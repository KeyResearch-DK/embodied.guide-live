Yes only if the developer itself says the model runs on different robot models, for example robots from two manufacturers or two of one manufacturer’s models. Several units of the same robot do not count.

Notes

Model type

Model card: “EO-1 model is a Vision-Language-Action (VLA) model that adopts a single unified decoder-only transformer”; it is built “for multimodal embodied reasoning and robot control, enabling seamless perception, planning, reasoning, and acting in single model”.

What it controls

Model card, Output: “Output Type(s): Actions, Language”. The real-robot tests are arm and dual-arm manipulation tasks: “Agibot G-1 Long-Horizon Dexterity (4 Tasks).”

Inputs

Model card, Input Type: “Vision: Image Frames, Video”; “State: Robot Proprioception”; “Language Instruction: Text, Pointing, Bounding Box, etc.”. Image frames and video = camera, robot proprioception = robot state.

Parameters
