Notes

Black Forest Labs describes FLUX 3 Action on its blog and in its code repository as a world action model.

The base-weights repository on Hugging Face says it is part of a collection with separate ready-to-use policies for two robot setups.

Black Forest Labs lists its labs on its own website.
