Notes

NVIDIA describes Isaac GR00T N1.7 as an open vision-language-action model for generalized humanoid robot skills.

NVIDIA pretrained N1.7 on 20K hours of human video alongside robot demonstrations.

NVIDIA announced N1.7 as available in early access on 16 March 2026; the GitHub release tagged n1.7-release (titled “Early Access n1.7 release”) followed on 18 April 2026, and the repository now calls it a General Availability release.
