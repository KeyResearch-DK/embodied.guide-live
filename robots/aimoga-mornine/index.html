Notes

AiMOGA's own site (Moga Technology Co., Ltd, per the page footer) names the robot only “Mornine”, with no model-number suffix such as “M1”.

The 40-degree-of-freedom figure is given only as a single full-body total; the page provides no breakdown by body part (arms/legs/head/hands).

AiMOGA describes an on-device “MoNet” large language model (6-billion-parameter, mixture-of-experts, “terminal-side deployment”, claimed 5ms/token inference); this is a software/AI-model description, not a hardware compute platform, so no onboard-compute chip is named.
