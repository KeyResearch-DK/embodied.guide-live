Notes

Robot World reports that LINX Robot unveiled its first self-developed wheeled humanoid robot on 14 May 2026 (translated from the Chinese).

The same report describes a symmetrical structure that allows mirrored operation facing forward or backward, and an industrial dual-differential chassis for narrow aisles (translated from the Chinese).

Weekhao calls the robot an integrated mobile manipulation platform built for real factories (translated from the Chinese).

The press headlines name the robot LINXROBOT-L1, while the body text of Robot World's report calls it LINXROBOT-L (translated from the Chinese).
