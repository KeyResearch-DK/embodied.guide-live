What the data labels mean

Notes

  • Google DeepMind introduced RT-2 as a vision-language-action model that learns from web data and robot data.
  • RT-2 comes in two versions, built on two different vision-language models, PaLM-E and PaLI-X.
  • Google DeepMind published the RT-2 blog post and paper on 28 July 2023.
Versions and notes in the key figures (5)

Model type

Developer wording: "Robotic Transformer 2 (RT-2) is a novel vision-language-action (VLA) model that learns from both web and robotics data, and translates this knowledge into generalised instructions for robotic control".

Controls

The action is a string of tokens that starts with an end-of-episode flag and then gives "commands to change position and rotation of the end-effector, as well as the desired extension of the robot gripper".

Inputs

"The resulting model takes in robot camera images and directly predicts actions for a robot to perform." "The robot data includes the current image, language command and the robot action at the particular time step."

Parameters

Note One number per version: "RT-2 trained on top of PaLM-E (12B parameters)"; "RT-2 trained on top of PaLI-X (55B parameters)".

Base model

"we adapt Pathways Language and Image model (PaLI-X) and Pathways Language model Embodied (PaLM-E) to act as the backbones of RT-2".
